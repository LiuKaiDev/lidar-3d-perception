# v0.7.0-rc1 发布说明

这是一个 release candidate，不是稳定版 `v0.7.0`。本版本将 LiDAR 三维检测项目整理为可复现的工程入口：包含 KITTI/nuScenes 数据适配、几何工具、统一 prediction schema、缓存 provenance、评估、E3 融合、验证命令和实验报告。

## 主要内容

- 默认 detector 为 VoxelNeXt；CenterPoint 用作 baseline。
- E3 是可选的顺序 late-fusion directional ablation。它提高远距离/稀疏目标的 custom recall，但增加 FP，官方 mini_val mAP/NDS 低于 VoxelNeXt。
- 提供只读 CPU/GPU 环境与资产检查，以及 nuScenes 单样本 demo。
- GitHub Actions 在 Python 3.12 上运行 asset-free CPU tests，不初始化 detector。
- [Phase 6 结果摘要](../../reports/phase6_summary.md) 从冻结 E3/E4 JSON artifacts 确定性生成。

## 使用入口

```bash
PYTHONPATH=. .venv/bin/python tools/validate_environment.py --profile cpu
PYTHONPATH=. .venv/bin/python tools/validate_environment.py --profile gpu
PYTHONPATH=. .venv/bin/python tools/validate_assets.py --detector voxelnext
PYTHONPATH=. .venv/bin/python tools/demo_nuscenes.py --sample-token <token>
```

GPU 推理需要兼容的 CUDA Torch/spconv、固定 revision 的 OpenPCDet、nuScenes 数据和与配置 SHA-256 匹配的 checkpoint。dataset、checkpoint、PredictionCache、evaluator dump 和 runtime outputs 不随仓库或 release 分发。

## 实验范围与限制

Phase 6 是 `nuScenes v1.0-mini exploratory experiment`。`mini_val` 只有两个此前已暴露的 scene，不是 full nuScenes benchmark，不证明 full nuScenes 泛化，也不是 SOTA claim。Phase 5 detector E2E、E3 顺序总耗时估算和 demo cold/warm CLI wall time 的计时范围不同，不能直接比较。

后续工作包括在新 split/full nuScenes 上验证和 tracking；本 RC 不发布 PyPI，也不创建稳定 `v0.7.0`。
