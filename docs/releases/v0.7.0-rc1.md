# v0.7.0-rc1 Release Notes

Status: **GitHub prerelease candidate; tag `v0.7.0-rc1`**.

This release candidate packages a reproducible LiDAR 3D detection portfolio
around project-owned dataset adapters, geometry, prediction schemas, cache
provenance, evaluation, late fusion, validation CLIs, reports, and tests. The
pinned OpenPCDet submodule remains the third-party detector backend.

## Highlights

- VoxelNeXt is the default detector; CenterPoint remains the baseline.
- Frozen E3 sequential late fusion remains an optional directional ablation.
  It improves far/sparse custom recall but adds false positives and trails
  VoxelNeXt on official mini-val mAP/NDS.
- Read-only CPU/GPU environment and model-asset validation entrypoints.
- A single-sample nuScenes demo with explicit detector selection.
- Python 3.12 GitHub Actions CPU coverage without model initialization or
  external assets.
- A deterministic [Phase 6 summary](../../reports/phase6_summary.md) generated
  from committed E3/E4 artifacts.
- Original project code and documentation are licensed under Apache-2.0.

```bash
PYTHONPATH=. .venv/bin/python tools/validate_environment.py --profile cpu
PYTHONPATH=. .venv/bin/python tools/validate_environment.py --profile gpu
PYTHONPATH=. .venv/bin/python tools/validate_assets.py --detector voxelnext
PYTHONPATH=. .venv/bin/python tools/demo_nuscenes.py --sample-token <token>
```

## External Requirements And Ownership

nuScenes/KITTI data, pretrained checkpoints, prediction caches, and runtime
outputs are not distributed in this repository. GPU inference requires the
pinned OpenPCDet revision, a compatible Torch/CUDA/spconv environment, local
nuScenes assets, and a checkpoint matching the SHA-256 identity in the detector
config. See [third-party and asset boundaries](../15_third_party_and_assets.md).

## Scope And Limitations

Phase 6 is a `nuScenes v1.0-mini exploratory experiment`. Mini-val contains two
previously exposed scenes. The results are not a full nuScenes benchmark, do not
establish full-dataset generalization, and are not a SOTA claim. Detector E2E
measurements, estimated E3 sequential latency, and Phase 7A CLI wall time have
different timing scopes and must not be compared as equivalent measurements.

The package metadata is synchronized to `0.7.0rc1`. This is a release
candidate, not the stable `v0.7.0` release. The project Apache-2.0 license does
not relicense OpenPCDet, datasets, checkpoints, or other external assets.
